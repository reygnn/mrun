# Review 2026-11-18

Twelve reviewers over mrun.c, tests/ui.sh and the docs: memory, performance,
robustness, the hot path, hacks, test coverage, the test harness, Wayland, process
start and security, text input, drawing against mwc's `src/draw.c`, and docs against
code. Memory, performance, the hot path and Wayland had no findings, and none of the
fixes of 11-17 was found wrong. Every point was checked against the code; two that
two reviewers found are listed once. Every point below is settled.


## Fixed

| Point | Fix |
|---|---|
| Tab on a name it quotes (`two words`, `x=y`, `time`, `été`) emptied the list: the query was the quoted word | the first word is read as the shell splits it, quotes removed |
| A path without a blank went through `/bin/sh`, so a wrong one closed the window silently | a path of plain characters is started directly and its error shown; one with `~`, `$` and the like still goes to the shell |
| The child wrote to stderr before the pipe, so SIGPIPE from a dead stderr made mrun quit as if it had started | the pipe first |
| A click, a new list and a click on the same row ran the program in that row now | a new list ends a double click |
| On EPIPE from the flush mrun quit with "Success", before reading the compositor's error | reads on, and the dispatch reports it |
| Matching ignored case only for ASCII | names and query are compared case folded |
| A name starting right to left was drawn against the right edge | auto direction off, rows stay left aligned |
| `MRUN_TEST_STATE=` turned the test hook on and wrote `./.tmp` on every loop | empty counts as unset |
| Ctrl+U, Ctrl+Q and Ctrl+W did nothing in a layout without Latin letters | the key of the first layout, as GTK and Qt read it |

## Tests

`expect_ran` waited for the mark to exist, not to be written; it waits for content
now. The focus test waited for the second mrun's first draw, which comes before it
has the keyboard, and could pass with the focus never moved; it now waits in mwc's
state until the second has the keyboard, and after it ends until the first has it
back. "The environment before mwmrc" ran with no mwmrc, and "the last line that says
it" had only one line that counted; both have a real mwmrc now.

Added: Tab on a quoted name keeps it chosen and a second Tab changes nothing, a path
that isn't there, a name found in another case that isn't ASCII, stderr a broken
pipe, an empty `MRUN_TEST_STATE`, a right to left name, Up to the last and Down past
the rows shown scroll, the wheel stops at the end, two clicks on two lists, slow
clicks, right and middle clicks, typing clears an error, closing from the compositor,
maximize and back, Ctrl+U and Ctrl+Q in a Russian layout (vinput's `group`, mwc
584f35d), losing the keyboard stops a repeating key, `MRUN_FONT` with and
without a size, `Mwm*background`, and valid `rgb:` colours. Each test of a fix, and
each new test of code already there, was checked to fail with that code taken out.

Not covered: EPIPE from the flush, which needs a compositor that closes with requests
still queued.
