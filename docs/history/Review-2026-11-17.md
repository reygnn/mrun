# Review 2026-11-17

Eight reviewers over mrun.c and tests/ui.sh: memory, performance, robustness, the hot
path, hacks, happy and sad path tests, Wayland protocol and lifecycle, and process
start and security. Memory had no findings. Every point below is settled.


## Fixed

| Point | Fix |
|---|---|
| A directory named twice in `$PATH` (merged /usr, profile duplicates) was read twice | read once, by device and inode |
| `%.200s` and snprintf could cut the status line inside a UTF-8 character | cut on a character |
| A line starting with `-` was read by `sh -c` as options | `sh -c -- line` |
| Tab left a name with `=` or a reserved word unquoted | quoted |
| Typing the arguments rebuilt the list and chose the first match again | the list and the choice stay while the first word is the same |
| A double click whose name didn't fit ran the line as typed | runs nothing and says so; a line that just fits is taken |
| Every configure, also for focus, scrolled back to the choice | only a new size does |
| With stderr closed the Wayland socket could be fd 2, and a failed exec wrote into it | fds 0 to 2 are opened on /dev/null at the start |
| A failed first roundtrip was reported as missing globals | reported as a lost connection |
| Keys and wheel turns that change nothing repainted, also when repeated | they don't |
| The cursor theme was loaded at scale 1 and again at once on a scaled output | loaded at the first enter |
| A line of blanks went to the shell and quit | as an empty line |
| repeat_info with rate 0 didn't stop a key that was repeating | it does |


## Tests

`mrun_sync` waited for any key count to grow, which a key still queued before F6
could do; it now waits for a counter of F6 alone. That race depends on timing, so no
test pins it. Matches after Ctrl+U are read after a sync, and the row geometry is
measured in one screenshot once the row is drawn.

Added: editing a character of two bytes, a name that isn't ASCII, a start after a
failed exec, two clicks on two rows, Up with nothing chosen, and a test for each fix
above. Each was checked to fail with its fix taken out. The repeat test needs mwc's
`Mwm*keyboardRepeatRate` (mwc 335d7fe).

mrun writes `syncs`, `dirs`, `draws`, `dirty` and `cursors` to `MRUN_TEST_STATE` for
these tests.
