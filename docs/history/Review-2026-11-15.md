# Review 2026-11-15

Four reviewers over the whole code base: memory and Wayland lifecycle, logic and
input, drawing against mwc's `src/draw.c`, and tests, build and docs. No crash or
write outside a buffer was found. Every point below is settled.


## Fixed

| Point | Fix |
|---|---|
| A failed exec went unreported; the window closed and nothing started | errno comes back through a CLOEXEC pipe, mrun stays open and says why |
| execvp searched relative `$PATH` entries the list leaves out | a name is started by the path it was found at |
| `Mwm*foreground` was ignored | it is the text colour where set, as in mwc |
| A key that cancelled a compose sequence was dropped | only a character is dropped; Esc, Return and arrows work |
| Names differing in case sorted in any order, duplicates could stay | ties broken by case, then by `$PATH` order; the name as typed first |
| Tab put a name with a blank or quote unquoted before the shell | single quotes where the shell needs them |
| `rgb:` took a sign, blanks and `0x` | hex digits only |
| The rest of a long mwmrc line was read as a line | skipped |
| The keymap was read as a C string | read up to its size |
| A buffer over 2 GiB went to a shm pool with an int32 size | exits with a message |
| No lower bound on protocol versions | wl_compositor 4 required; seat below 5 and 3 handled |
| The cursor surface could keep a destroyed buffer; a failed load was never retried | buffer dropped first; retried at the next enter |
| Pango laid out at scale 1 on a scaled buffer | updated to the buffer's scale |
| The status text was not clipped | clipped to the status bar |
| The chosen row had no bevel | raised, as mwc's armed menu item |


## Tests

`still_open` waited a fixed time; it now waits for a key mrun ignores to come
through, read from `MRUN_TEST_STATE`. The end-of-list test passed also for a list
that wraps, the wheel test never checked scrolling, and the cursor test didn't check
the pointer was on the window; all three check it now. Added: the status messages,
a path and shell syntax for the shell, Page Up/Down, Home, End, Delete, KP_Enter,
Shift+Tab, compose, names not offered, the colours from the environment and mwmrc,
and the exit codes of `-v`, `-h` and an unknown option. Each new test was checked to
fail with its fix taken out where that was cheap.

Not covered: key repeat (vinput can't hold a key), and the fixes for old
compositors, a keymap without NUL, huge buffers, the Pango scale and the status
clip, which a headless mwc can't provoke.


## Left as they are

The dim status text and the chosen row's text colour differ from mwc on purpose;
see `CAVEATS.md`. A shell line gets `$PATH` as it is, relative entries included.
